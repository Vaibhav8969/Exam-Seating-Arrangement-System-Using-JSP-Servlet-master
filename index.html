Exam Seating Arrangement System

A Web Application for Managing Exam Halls, Blocks, Rooms, Seats & Students

Technology Stack & Architecture

Java EE 8 Apache Tomcat 9 JSP & Servlets MySQL 8.0 Docker Ready

This backend system requires a Java Virtual Machine (JVM) and Apache Tomcat 9 servlet container along with a MySQL database.

Cloud Deployment Notice: Because this project is built on Java Servlets & JSP, it runs in a Docker container on Render.com, Railway.app, or Fly.io.

Core Features

  • Room & Floor Management: Add and organize exam rooms by building and floors.
  • Block & Seat Configuration: Define blocks within rooms and allocate seat numbers.
  • Student Seat Allocation: Assign students to individual seats automatically or manually.
  • Student Seat Search: Search and view assigned seat cards by Roll Number.
  • User & Admin Access Control: Super-admin dashboard, authentication, and user management.
